# FXのToolを作る

FXをデータにしたら、次はToolにする。

ここでいうToolは、自動で売買する機械ではない。自分が市場を観察し、仮説を作り、あとから検証できるようにするための道具だ。

最初は小さくていい。USD/JPYの15分足を読み込み、チャートを表示する。そこからreturnや値幅、SMA、EMA、ボラティリティなどを計算する。その特徴量をBQMLに渡し、「次の15分は上か下か」を確率として保存する。そしてJEVに現在の価格、トレンド、モメンタム、ボラティリティ、BQMLの予測を渡す。

流れはこうなる。

観測 → 特徴量 → BQML → JEV → 記録 → バックテスト

この一連の流れがToolになる。

やまっけのある人ほど、ここでToolが効いてくる。勢いで「行けそうだ」と思った瞬間、その理由を記録できるからだ。予測は何％だったか。JEVはどういう文脈として読んだか。その後、本当に価格はどう動いたか。感覚をそのまま消費せず、次の研究材料にできる。

重要なのは、Toolが判断を奪わないことだ。BQMLは予測を作る。JEVは文脈を整理する。最終的な行動とリスク管理は人間が考える。

最初から完璧なToolを作る必要はない。

「荒く作る → 使う → 記録する → 比較する → 絞る」。

この反復によって、ただのチャートが、自分の勘を研究するための実験装置になっていく。

FXの面白さは、Toolを作ること自体にもある。
